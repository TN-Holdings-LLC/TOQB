## Steps

1. Probe job (`os3d_probe.py build`): the floor at t = 3 of the first 4 qualifying fold translations in the fixed
   order, every touched qubit read (sites and bridges). Submit, collect, `os3d_probe.py choose`.
2. Rule: the chosen translation is the first candidate whose touched qubits all read floor >= 0.8. If none does: a
   line "probe passed none", and the main job is built without --choice (A = first translation vs B, as the first
   run of the night).
3. Main job (`os3d_compare_build.py ... --choice CHOICE.json`): A = fold at the chosen translation; A0 = fold at the
   first translation, only when the probe passed some over; B = SABRE seed 0; t = 1, 2, 3; floor and mirror each;
   ring sentinel; 4000 shots.
4. Calibration beside at submit and at run (report only, as the first run).
5. Score with `os3d_probe_score.py`; commit; then release the answers.

## Judged

- Per arm and t: READS, AGREES, BEATS (gpu/practice_score.judge; BEATS against every <Z> = 0 or every <Z> = 1).
- Per t: R = MSE_A / MSE_B (HELPS <= 0.8, HURTS >= 1.25, NO EFFECT between).
- Per t, when A0 is in the job: R_probe = MSE_A / MSE_A0 with the same thresholds.
- Beside: the probe's floors per candidate and the chosen index, retention, normalised error, CZ and layers, floor
  and mirror, sentinel, calibration beside.
