## Where this comes from, and what is new here

The XX size test of today (`prereg/xxsize_2026-11-14.md`, verdicts in `notes/xxsize_2026-11-14/README.md`) found r
lower at N = 81 than at N = 33. After the verdicts, an exploratory split (`notes/xxsize_2026-11-14/split.py`) found on
marrakesh, where the N = 33 chain is exactly the first 33 qubits of the N = 81 chain, that the same qubits keep less
inside the longer circuit, that the added qubits are not worse, and that the gap grows with depth. Split by position
(`notes/xxcone_2026-11-14/cone.py` on today's records), the gap starts in the block next to where the longer chain
continues and moves inward with depth; at theta = pi/2 (the fastest spreading) it reaches the far block only at 48-64
layers. The reading: in this circuit errors spread along the chain with the dynamics, so a qubit's shrink counts the
errors inside its light cone, which the 33-qubit chain cuts off at its end.

**The three predictions below were chosen after seeing today's data, and they hold on it.** What this run tests is
whether the same pattern comes back in a new job on the same device: a repeat, not a first test. The answers are the
free-fermion values already released (`notes/xxsize_2026-11-14/answers_released/`); the predictions are about the
device's r, not about the answers.

## Circuits and device

The same two jobs as the XX size test on ibm_marrakesh: `gpu/ffxx91.py DEV OUT ANS --n 33` and `--n 81`, `--steps
2,4,8,12,16`, theta pi/4 and pi/2, 34 circuits and 40.9 s by the model each (82 s in all); mirror, ring sentinel,
4000 shots, no correction, no mitigation, dynamical decoupling and twirling off; psf-os 0.1.1. ibm_marrakesh only.
Not run if the night's record gives an N = 33 chain that is not the first 33 qubits of the N = 81 chain (`cone.py`
checks it), or if either job does not build. Pre-run check: as in `prereg/xxsize_2026-11-14.md`; a build with the
circuits_sha256 of today's checked marrakesh try-builds (e039d746..., e4d434d6...) carries their PASS.

## Analysis (fixed: `notes/xxcone_2026-11-14/cone.py RUN33 RUN81`, after `gpu/hub_score.py` on each job)

Blocks by position in the N = 33 chain: far 0-10, mid 11-21, near 22-32 (the N = 81 chain continues past 32). In each
block, g = r(N = 33 circuit) - r(N = 81 circuit) on the same qubits.

## Predictions

1. theta = pi/4, far block: |g| <= 0.03 at all five depths (8 to 64 layers).
2. theta = pi/4, at 16 and 32 layers: g(near) - g(far) >= 0.05.
3. theta = pi/2, far block: |g| <= 0.03 at 8, 16 and 32 layers, and g >= 0.03 at 64 layers.

Each holds or fails as a whole. On today's records (`cone.py` on `results/xxsize-2026-11-14-marrakesh/`): pi/4 far
gaps +0.001 / -0.021 / +0.019 / +0.006 / -0.015; near minus far +0.113 and +0.148; pi/2 far gaps +0.002 / +0.014 /
+0.007, and +0.084 at 64 layers.
