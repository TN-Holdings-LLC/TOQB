## Problem

The lattice Schwinger model in the standard form of Martinez et al., Nature 534, 516 (2016) (Kogut-Susskind staggered
fermions, open chain, gauge field eliminated, Jordan-Wigner; `gpu/schwinger.py`, VS Claude's module, copied
unchanged), parameter sets M1 (w = J = 1, m = 0.5), M2 (w = J = 1, m = 0), M3 (w = 1, J = 2, m = 0), all from that
paper; start: the bare vacuum; first-order Trotter steps of dt = 0.25 (fixed before any answer was computed), the
long-range ZZ terms by a swap network (every pair of sites meets once per step; 3 CZ per gate; even steps reversed).
Circuits: N = 6 and 8, steps 1, 2 and 5, M1-M3: 18 circuits, CZ 45 / 90 / 225 (N = 6) and 84 / 168 / 420 (N = 8).
Steps 3 and 4 are left out: their exact values are near 0 (all-zero guess MSE 0.02-0.04), so they test little.
Exact answers: the Trotter circuit's own output (full statevector), not the continuous-time evolution.

## Verdicts (`gpu/schw_score.py OUT ANS`), per circuit

- nMSE = mean_n (z_n - e_n)^2 / mean_n e_n^2 (main measure); READS if MSE <= mean square / 2.
- BEATS if MSE is below both guesses: the bare vacuum and all zero (both printed beside).
- Particle density nu = (1 / 2N) sum_n (1 + (-1)^n z_n): AGREES if |nu - nu_exact| <= 0.05.
- Charge sum_n z_n (exact 0, conserved): reported as a raw check; never used to change a value.
- Floors, mirrors and the sentinel as recorded.

the N = 8 step-5 circuits (420 CZ, 105 per qubit, beyond the per-qubit exposure read so far) may not.
