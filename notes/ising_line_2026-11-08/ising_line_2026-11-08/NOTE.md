## 指示の 2：Ising の線の方式（`ising_line.py`）

**入口と戻り値**
- `grid3d.physical` と同じ形にしました：`physical_line(dev, L, M, N, t, theta, info=False, avoid=())` → `qc, placed, used[, passes, where]`
- `prepare_line(...)` は `grid3d.prepare` と同じ流れです：`rzz_exact` → RuleCompiler の pass manager → 床 → 鏡 → `accept`。

**作り**
- 格子の行 y の2ブロック（z = 0, 1）を、heavy-hex の行 r0 + y の8列に、交互に混ぜて並べます。
- x 方向と z 方向の結合は、その場の RZZ(−π/2)（1 CZ）か、入れ替えに相乗りした SWAP·RZZ（psf-os の `_swap_bond`、2 CX）で入れます。
- y 方向の結合は CX(a,b) RZZ(b,q) CX(a,b) です（橋げたは |0> に戻ります）。
- ステップごとに RX(θ) をかけ、偶数ステップは手順を逆向きに流します。

**置き方**
- すべての (r0, c0) を、「手順の安い順 → r0 → c0」の決まった順で試します。故障した量子ビットや結合器に触れない最初の場所を使います（点数で探すことはしません）。
- c0 が奇数で橋げたが位置 (2,6) や (0,4) に来るときは、手順を左右反転して使います。

**手順**

| 橋げたの位置 | 手順 | 1本の線あたりの空の入れ替え |
|---|---|---|
| 4×2×2、{1,5} | 総当たりで見つけたもの | 0回 |
| 4×2×2、{3,7} | 総当たりで見つけたもの | 2回（0回と1回は存在しない） |
| 4×3×2、{1,5} と {3,7} の両方 | 深さ優先探索で見つけたもの | 2回（0回と1回は見つからず、無いという証明ではない） |

**確かめたこと**（`check_line.py`、`check_out.txt`）

CZ は、psf-os の RuleCompiler を通した数です（`rzz_exact` のあと）。θ = 0.6 です。

| 記録 | 格子 | 線（t1 / t2 / t3 / t4） | 1ステップ | 折りたたみ v3.1 | 折りたたみ v3.2 |
|---|---|---|---|---|---|
| fez / kingston / marrakesh | 4×2×2 | 60 / 120 / 180 / 240 | **60** | 108 | 92 |
| fez / kingston / marrakesh | 4×3×2 | 126 / 252 / 378 / 504 | **126** | 234 | 222 |

- 置き場所は次のとおりでした。
  - 4×2×2：3台とも r0 0、c0 1（橋げた {2,6}、反転した手順）
  - 4×3×2：fez と kingston は r0 0、c0 0、marrakesh は r0 0、c0 7（反転）
- psf-os の `accept`（床と鏡の決まりの確認）は、すべての場合で全項目を通りました。
- 雑音なしで、`grid3d.exact` と比べました（fez の記録、θ 0.6）。

| 格子 | t | 量子ビット | 配置 − 厳密 | 橋げたが |0> に戻る |
|---|---|---|---|---|
| 4×2×2 | 1〜4 | 18 | ≤ 3.9e-14 | ≤ 3.8e-14 |
| 4×3×2 | 1, 2 | 28 | ≤ 7.3e-12 | ≤ 6.1e-12 |

  - 4×3×2 は、28量子ビットの状態ベクトル（Aer、各格子点の <Z> だけを出す）で確かめました。

**未確認のこと**
- psf-os の `build` や `probe_records` など、ジョブを組む側への組み込み（`layout="line"` の追加）は、まだしていません。`prepare_line` の戻り値は `prepare` と同じ形なので、`write_records` にそのまま渡せる見込みです。
- (y, z) を入れ替えた置き方（fold の `swapped`）には、まだ対応していません。
- 4×3×2 の t3・t4 の雑音なしの確かめは、していません（時間を節約するため。CZ の数は出してあります）。
- 4×4×3、4×6×3 への拡張はできていません。前回の C で、乱数による探索は打ち切っています。
