## 最初に：前回の E の訂正（重要）

- fez の校正には `rzz`（分数ゲート、352本）と `rx` の誤差が載っています。
- 前回の E の「CZ ごとに RZZ(0.02) を足す」確かめで、私は普通の `rzz` ゲートを足していました。そのため雑音の模型が、足したゲートにも `rzz` の誤差を付けていました。結果として、ε の大きさに関係なく、CZ 1つにつき2量子ビットゲート1つ分の誤差が足されていました。
- 今回の1回目の計算でも同じ誤りが起き、ε = 0.01 / 0.02 / 0.04 でほぼ同じ大きな劣化が出ていたことで気づきました。結果は `pod_out/out_first_run/` に残してあります。
- **前回の E の「Heisenberg が 1.20 → 0.75」という結果と、それを根拠にした「CZ の位相のずれが有力」という仮説は撤回します。**
- 直し方：足すずれを、雑音の付かない `UnitaryGate`（行列は RZZ(ε)・RX(δ) と同じ）にしました（`kit/expsim3.py` の `_err_gate`、確かめは `kit/check_err.py`）。
- 直したあとの値では、ε = 0.02 での Heisenberg の前向きの保持率の下がり方は t1〜t4 で 1% / 4% / 8% / 14% でした（下の 5）。E の比 1.20 は、これを掛けると t ごとに 1.19 / 1.13 / 1.17 / 1.03 程度になります。ε = 0.02 だけでは、E のずれ全体は説明できません。

## やったこと

- **鏡1**：往復の回路（U·U†）を、そのまま流しました。
- **鏡2**：同じ往復の回路で、CZ ごとにランダムなパウリの枠を入れたものです。
  - 前の枠を P、後ろの枠を P' = CZ·P·CZ† としました。こうすると、理想の回路は変わりません。
  - 足すずれは CZ の直後、つまり枠の内側に置きました。
  - 枠そのものには雑音を付けていません（隣の1量子ビットゲートに吸収される、という仮定）。
  - 雑音なしで、枠を入れた回路と入れない回路の <Z> が一致することを確かめました（ずれ 2e-15 以下、`kit/test_twirl_out.txt`）。
- **軌道の数**：鏡1は160軌道です。鏡2は16通りの枠 × 10軌道です。鏡2の標準誤差は、枠ごとの平均のばらつきから出しました。
- **見た量**：測る量子ビットの <Z> の平均（理想は1）です。D = 鏡2 − 鏡1 とします。
- **対象**
  - Heisenberg B：場所0、t1〜t4 の往復の回路（4本）
  - Ising A：場所3、θ 0.4/0.6/0.8 × t1・t3・t6 の往復の回路（9本）
  - 前向きの回路：Heisenberg の t1〜t4 と、Ising の同じ9腕
- **足したずれ**：CZ ごとの位相のずれ ε = 0 / 0.01 / 0.02 / 0.04 rad と、sx ごとの回しすぎ δ = 0.01 rad です。
- **POD**：2026-11-08 11:04〜12:08 CET（約64分、1回目と直したあとのやり直しを含む）、約2.4ドルでした。POD は削除済みです。

## 4-2. ε = 0 で D は 0 と見分けがつかないか

**確かめたこと**
- 13本すべてで、D は 2SE 以内でした。最も外れたものでも −1.6SE です。
- ただし、Ising の9本は ε = 0 でもすべて D が負でした（平均で約 −0.012）。1本ずつでは 2SE 以内ですが、符号がそろっています。ぼかしそのもので、Ising の鏡が少しだけ悪く見える可能性があります。
- Heisenberg の ε = 0 の D は、正と負が混ざっていました。

## 4-3. D は ε と深さで大きくなるか

**確かめたこと**
- **Heisenberg**：D は ε が大きくなるほど大きくなりました（ε = 0 を引いた値）。
  - ε = 0.01 では、ほぼ0でした。
  - ε = 0.02 では +0.004〜+0.012 でした（160軌道では 2SE 未満）。
  - ε = 0.04 では +0.021〜+0.058 で、t2〜t4 で 2SE を超えました。
  - ε を2倍にすると、D はおよそ4〜5倍になります。ε の2乗に近い増え方です。
  - 深さについては、t1 から t3 まで大きくなり、t4 では横ばいでした。t4 は鏡1がすでに0.08まで下がっていて、下げる余地が少ないためだと考えています。
- **(nε)² と nε² の見込みとの比較**
  - (nε)²（ずれがそろって積み重なる場合）の見込みより、桁違いに小さい値でした。
  - D ÷ (nε²) はおよそ 0.02〜0.05 で、おおむね一定でした。
  - この回路では、ずれが一方向にそろって積み重なってはいない、と見ています（解釈は家の Claude に任せます）。
- **Ising**：ε を入れても、D はほとんど動きませんでした。鏡1も鏡2も、ε でほとんど変わりません。
- **sx の回しすぎ δ = 0.01**：どちらの模型でも、D は 2SE 以内でした。CZ のずれとは見分けがつきませんでした（どちらも見えない、という意味で）。

## 4-4. Heisenberg と Ising の違い

- Heisenberg は、CZ のずれに対して、鏡1（そろったまま）が鏡2（ぼかした）より大きく下がりました。そのぶん D が出ます。
- Ising の鏡は、どちらもずれにほとんど反応しませんでした。なので、Ising では D は検査になりません。

- 鏡2枚から本番の劣化を言い当てられるのは、Heisenberg で、ずれが大きい（ε ≥ 0.04 程度）場合に限られそうです。

## 4-6. 実機での費用の見積もり

- 前提は次のとおりです。
  - 1回路のショットの雑音は、v = (1 − m²)/16 としました（16量子ビットが独立という仮定）。
  - 枠ごとのばらつきは、シミュレーションの値を使いました。16枠 × 10軌道からの見積もりなので、粗い値です。
  - 実機の時間は、ショットの数に比例するとしました。
- ε = 0.02 の D（点推定）を 2SE で見分けるのに必要なショットの数は、Heisenberg で次のとおりでした。

| 回路 | 必要なショットの数 |
|---|---|
| t3 | 約1000 |
| t4 | 約4000 |
| t1 | 届かない（枠ごとのばらつき 0.036 が D 0.005 より大きい） |
| t2 | 64枠で約7500 |

- 鏡2を全部の腕（48本）に4000ショットずつ足すと、実機の時間は約1.32倍です（今の heisE は148本・168秒）。IBM Runtime の組み込みのツワーリング機能を使っても、ショットの数は同じなので、時間の増え方はほぼ同じと見ています。
- 回路の本数は、枠を別の回路として作ると、48腕 × 枠の数だけ増えます。組み込みの機能を使えば、増えません。

## 5. 判定（先に決めておいた目安による）

| 目安 | 結果 |
|---|---|
| ε = 0 で D が 2SE 以内 | **満たす**（13/13。ただし Ising は符号がそろって約 −0.01） |
| ε = 0.02 の D が、実機の時間 1.5倍以内の費用で 2SE を超える | **満たさない** |

2つ目を満たさない理由は次のとおりです。
- シミュレーションでも、ε = 0.02 の D は 160軌道で 2SE を超えませんでした。点推定は 0.005〜0.022 で、それ自体のばらつきが ±0.013〜0.021 あります。
- 1.32倍の費用で届く見込みがあるのは、Heisenberg の t3（と境目の t4）だけです。t1・t2 と Ising には届きません。

**判定：先に決めた目安では「鏡2を検査として足さない」。**

参考までに、ε が 0.04 程度と大きい場合は、Heisenberg の t2〜t4 で D がはっきり出ます。
