## A. 本当の差か（`scripts/a_boot.py`、`out/a_out.txt`、`out/a_out_marrakesh.txt`）

**方法**
- 生のカウントから、ショットごとのネール秩序 m_s を出しました（測定ビット k = 格子点 k、符号は (−1)^(x+y+z)）。採点ファイルの m_s と完全に一致することを確かめています。
- 保持率 = m_s ÷ その腕自身の正解です。
- 標準誤差は、ショットのばらつきから出す式と、ショットのブートストラップ（4000回、腕ごとに別々に）の2通りで出し、両者は一致しました。

**確かめたこと（キングストン）**
- 実際の標準誤差は、t1 で約 0.0055、t4 で約 0.022 でした。宣言の線（0.048〜0.146）の、およそ6分の1です。

| 場所 | line − old（t1 / t2 / t3 / t4） | z |
|---|---|---|
| 0 | +0.029 / +0.044 / 0.000 / −0.000 | +5.2 / +5.5 / 0.0 / 0.0 |
| 1（判定） | +0.022 / +0.056 / +0.050 / **−0.051** | +3.9 / +6.7 / +4.0 / **−2.3** |
| 2 | +0.057 / +0.109 / +0.144 / +0.109 | +11.2 / +13.5 / +11.6 / +4.7 |
| 3 | +0.080 / +0.057 / +0.096 / +0.001 | +14.6 / +7.3 / +8.1 / +0.1 |

- **場所1・t4 の −0.051 は −2.3σ** です（ブートストラップの95%区間は −0.095〜−0.008）。ショットのばらつきだけで説明するのは難しい値です。ただし32個の比較のうちの1つなので、|z| ≥ 2.3 が偶然1つ出ることは、0.7個くらい起こり得ます。
- **場所0の t3・t4 の 0.000** は、差が無いと言えます（±0.013 / ±0.022）。
- **場所2の伸び**は、はっきり本物です。
- **marrakesh** も同じやり方で出しました。判定に使った場所1は、t1〜t4 のすべてで正（3.5〜10.5σ）でした。ただし場所3・t3 で line − old が −0.053（**−4.5σ**）でした。深い t で line が保持率で負けることは、2台ともに起きています。

## B. 場所による違いの原因（記録から）

**確かめたこと（記録の数字）**
- **鏡（往復）の平均は、2台・8か所・全 t で line が old より良い値でした**（`out/b_table_out.txt`）。キングストンの t4 では、old が 0.008〜0.109、line が 0.157〜0.223 です。
- 床（floor）の平均は、old と line でほぼ同じでした（0.976〜0.988）。
- **old の保持率は、t3 から t4 でほとんど下がらない場所があります。** 場所3では 0.495 → 0.499 で、そのときの old の鏡は 0.109 しかありません。
- 格子点ごとの正解とのずれ（MSE、`out/b_more_out.txt`）を t4 で比べました（line / old）。
  - 場所0：0.038 / 0.041、場所1：0.043 / 0.045、場所2：0.037 / 0.045 で、line のほうが正解に近いです。
  - 場所3だけ、0.041 / 0.037 で old のほうが近いです。
  - **場所1の t4 では、保持率は line が負けているのに、MSE は line が勝っています。**
- 結合ごとの CZ の数（t4、場所1と場所2）
  - old と line は、どちらも同じ18本の結合を使っています。
  - 1つの結合あたりの最大は old が64、line が52 です。どちらも、いちばん多いのは橋げたの結合（25-37、29-38 など）でした。
  - line の CZ が特定の結合に集まっている様子はありませんでした。
- 鏡の値がいちばん低い量子ビット（t4）
  - 場所2では、old が −0.19〜−0.23 の量子ビットを4つ持っていて、old の通り道に悪いところがあることを示しています。line では、いちばん低いものでも −0.01 でした。
  - 場所2の大きな伸びは、line が特に良いというより、old がそこで悪いことによる部分が大きいと見ています。
- 番兵は CLEAN でした。記録上の故障（112、113、121、146 と結合5本）は、4つの場所の、どの量子ビット・結合とも重なっていません。

**仮説**
- **仮説1（有力）：深い t の保持率は、回路のきれいさに比例しない。**
  - 正解の m_s は t4 で 0.30 まで下がりますが、雑音の多い回路では交換の動きが鈍り、ネール秩序が残りやすくなる可能性があります。
  - そうだとすると、鏡で明らかに悪い old の保持率が下がりにくくなり、line との差が t4 で消えたり逆転したりします。
  - 鏡と MSE が line を支持し、保持率だけが逆、という場所1・t4 の形と合います。
- 仮説2：場所1・t4 は、ショットの偶然（−2.3σ、比較の数を考えれば起こり得る）。
- 結合の弱さが原因という仮説は、CZ の数え上げからは支持されませんでした。

  - 2台・8か所すべてで、line の t1 の鏡が old より良かったので、規則は常に line を選びました。
