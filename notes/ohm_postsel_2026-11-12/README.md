## やり方（`postsel.py`）

回路（fSim と RZ）は、1 の総数を保ちます。そこで、撃ちのうち 1 の数が初期の文字列と同じものだけを残しました（往復の回路では、1 の数が 0 の撃ち）。

- 撃ちの読み方は `psf_os.user2d.card` と同じです。クラシカルビット k は、文字列の右から k 番目で、`rec["labels"][k]` に当たります。
- 初期値は、`build.json` の `strings` のビット i を、鎖のラベル `chain.labels[i]` の初期値としました。
- 残った撃ちだけで、`gpu/ohm_score.py` と同じ計算をしました（量子ビットごとの Z、M、MSE、AGREES、W など）。
- 混ざりの割合は p = (W − W答え)/(W混合 − W答え) です。W混合は、すべての Z が 0 のときの W で、両機種とも 5.5 です。
- 確かめたこと：すべての撃ちで計算し直した補正なしの数字は、`scores.json` と全項目で一致しました（差 0）。全回路の M、腕ごとの MSE・W・AGREES・量子ビットごとの READS・READS、指数を比べています。

## 注意（後選別の限界）

- 1 の数が同じでも、1つ増えて1つ減った撃ちは残ります。後選別した数字にも、数を変えない誤差と、打ち消し合った誤差が残っています。
- 残る撃ちは 10〜30% です。後選別した値の撃ちの誤差は、補正なしより大きくなります（この表には SE を入れていません）。
