## 定式化とパラメータ（出典）

- 指示書の標準形のまま。Kogut–Susskind のずらした格子、開いた境界、ガウスの法則でゲージ場を消去、Jordan–Wigner。
  H = w Σ(σ⁺σ⁻ + h.c.) + (m/2) Σ(−1)ⁿ Zₙ + J Σ Lₙ²、Lₙ = ε₀ + ½ Σ_{k≤n}(Z_k + (−1)^k)。
  出典：Martinez ら、Nature 534, 516 (2016)、arXiv:1605.04570 の式 (1) と Box I（論文の PDF で確かめた）。
- 展開（定数は全体の位相なので落とす）：ZZ の係数 A_kl = (J/2)(N − l)（k < l）、Z の係数 h_k = (m/2)(−1)^k + J Σ_{n=k}^{N−1} c_n、c_n = ε₀ + ½ Σ_{k≤n}(−1)^k。展開前の式と行列で一致（テスト）。
- パラメータ（3組、どれも論文の値、ε₀ = 0）：
  - M1：w = 1、J = w、m = 0.5w（論文の図2(a)）
  - M2：w = 1、J = w、m = 0（図3）
  - M3：w = 1、J = 2w、m = 0（図3）
- 初めの状態：素の真空（奇数サイト Z = +1、偶数サイト Z = −1。ν = 0）。
- 刻み：dt = 0.25/w（固定。答えを計算する前に決めた）、ステップ 1〜8（時間 wt = 0.25〜2.0）。

## 回路

- 1次のトロッター。1ステップ = Z の層（RZ）+ SWAP ネットワーク（偶数番と奇数番を交互に N 層。偶数ステップは逆順）。どの組も1ステップに1回だけ隣り合う。
- 各ゲートは SWAP · exp(−i dt [A_ab ZZ + (w/2)(XX+YY)（隣の組だけ）])。正準ゲート Can(π/4 − dt·w/2, 同, π/4 − dt·A_ab) として 3 CX で書いた（Vatan–Williams）。行列と一致（テスト）。
- CZ の数は 3·N(N−1)/2·ステップ、CZ の層は 3N·ステップ。
- サイトと量子ビットの対応は追いかけている。**run2d は、触れた量子ビットをラベルの順に読む**（古典ビット k = k 番目のラベル。`user2d.py` の説明どおり）。そこで回路もラベルの順に測り、古典ビット k がどのサイトを持つかは、追いかけた並びから決める（`schwinger.site_of_clbit`）。奇数ステップでは並びが逆になるので、これを入れないとサイトがずれる（途中で一度ずれていたのを見つけて直した。直したあとは、すべてのステップで一致）。
- 置き方：du91 の形の規則（`daily/du91.py` の SHAPES と lattice2d の平行移動）を先に試し、置けないときだけ `psf_os.chain.place`（規則 C）。今回は N ≤ 12 なので、3台とも形 S1（行 0、平行移動 (0,0)）で置けた。**規則 C を使う場面はなかった。**
- コンパイル：`psf-os run2d --device dev/ibm_XXX --circuit X.qpy --out <相対パス>`（オフライン、送信なし）。

- 模型の読みが「真空と推量」と「全部 0 と推量」の両方に勝つのは、**どの N でもステップ 1〜5**。ステップ 6〜8 は真空と推量に負ける（N = 6 でも）。
- ただし、ステップ 3〜4 は値がほぼ 0（全部 0 と推量しても MSE 0.02〜0.04）なので、雑音で値が縮んでも差が出にくく、試されるものが少ない。ステップ 1 は真空とほとんど変わらない（真空と推量して MSE 約 0.04）。
- 意味のありそうな候補は、ステップ 2 とステップ 5（値が真空からも 0 からも離れていて、模型で両方に勝つ）。たとえば N = 6〜8 の 2ステップ（CZ 90〜168）は、読めた記録と同じくらいの大きさ。

## 気づいたこと

1. SWAP ネットワークは CZ が N² で増え、1量子ビットあたりの CZ も N に比例する。N = 12 では 1ステップで du-stage2 一本ぶんになる。題材を広げるなら、N を増やすより、少ない N でステップを選ぶほうが現実的。
2. 1次トロッターで dt = 0.25 だと、値は「真空 → ほぼ 0 → 戻る」と振れる。ステップ 3〜4 は値がほぼ 0 で、当て推量（全部 0）でも当たりやすい。採点に使うなら、「全部 0」「真空」の推量を物差しに並べるとよい。
3. run2d はユーザーの古典ビットの割り当てを使わず、ラベルの順に読む。SWAP ネットワークのように、最後にサイトが入れ替わる回路では、答えをサイトでなくラベル（古典ビット）ごとに定めるか、対応表を一緒に封印する必要がある。
4. N ≤ 12 なら、3台とも形の規則 S1 でそのまま置けた（規則 C は不要）。
