## 模型（標準の形。違う形を使うときは出典と理由を書くこと）

- **定式化：** Kogut–Susskind のずらした格子のフェルミオン、開いた境界、ガウスの法則でゲージ場を消去、Jordan–Wigner でスピンの鎖にする。サイトは n = 1..N（N は偶数）。
- **ハミルトニアン：**
  H = w Σ_{n=1}^{N−1} (σ⁺_n σ⁻_{n+1} + h.c.) + (m/2) Σ_n (−1)^n Z_n + J Σ_{n=1}^{N−1} L_n²
  L_n = ε₀ + ½ Σ_{k≤n} (Z_k + (−1)^k)
- **パラメータ：** w、m、J、ε₀ は文献の値から選び、出典を書く（たとえば Martinez ら、Nature 534, 516 (2016) の値）。
- **初めの状態：** 素の真空（粒子数 0 のずらした積状態）。
- **見る量：** サイトごとの <Z_n> と、粒子数の密度 ν = (1/2N) Σ_n (1 + (−1)^n Z_n)。読み出しは Z だけ。

## 回路

1. **時間の進め方：** 1次（または2次）のトロッター分解、刻み dt は固定。採点に使う「答え」は、**トロッター回路そのものの厳密な出力**にする（今の方針と同じ）。連続時間の厳密値は、トロッター誤差の参考として横に並べるだけ。
2. **遠くの ZZ の入れ方：** L_n² を展開すると、全サイトの組の ZZ が出る。これを、隣どうしの入れ替えを順に並べる方法（SWAP ネットワーク：偶数番と奇数番を交互に N 層）で入れる。
   - 各ゲートは「入れ替え · ZZ(θ)」で、隣の組ならホッピング（XX+YY）もまとめる。1つ 3 CZ。
   - 偶数ステップは逆順で流す（今の grid3d と同じ考え方）。サイトと量子ビットの対応は追いかける。
3. **置き方：** Heron r2 のラベル上の鎖に書く。鎖は du91 の形の規則で取り、置けないときだけ `psf_os.chain.place`（規則 C）を使う。順番の案のとおりです。
4. **コンパイル：** ユーザーの回路として `psf-os run2d --device dev/ibm_XXX --circuit X.qpy --out <相対パス>` に通す。オフラインで、送信はしない。受け入れの検査（床・往復）が通ること、CZ の数と CZ の層の数を記録する。

## 確かめること

1. **雑音なしでの一致：** `run2d` がコンパイルした回路を、触れた量子ビットだけの状態ベクトルで計算し、サイトごとに厳密値と比べる（最大のずれを書く）。N が大きくて重いときは N ≤ 12 で十分です。
2. **候補の表：** N ∈ {6, 8, 10, 12}、ステップ数 1〜8 程度、パラメータの組を2〜3通り。各候補について次を書く。
   - CZ の数と層の数（`run2d` の出力）
   - 答えの大きさの目安（サイトごとの厳密値の二乗平均と、ν の大きさ）
   - 3台の記録で、どの鎖の置き方になったか（形の規則か C か）
3. **読めそうか：** 今までの記録と CZ の数・層の数を並べる（たとえば du51 / du71 で読めた深さ）。雑音の模型を使うなら、値を固定した一様な模型（CZ に 0.005 の脱分極、sx・x に 0.0002、読み出し 0.015）だけにして、実機に合わせて調整しないこと。

## 答えの扱い（大事）

あとで宣言するかもしれないので、**サイトごとの厳密値や ν の値そのものは、報告にも持ち帰りの表にも書かないでください。** 書いてよいのは、大きさの目安（二乗平均、ν のおおよその範囲）と、雑音なしでの一致の最大のずれまでです。厳密値を計算するコードは持ち帰ってかまいません。値は宣言のときに、封印してから計算し直します。
