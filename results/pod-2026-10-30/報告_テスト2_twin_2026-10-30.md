## 1. 結論

- **反響は電荷よりずっと速く消えます。** 往復の測定値 ρ_E は、rule の D = 24 で 0.08〜0.10 でした。10/29 に実機で測った電荷の減衰長（L* = 56.5）から見込んでいた値は 0.65 なので、その約 8 分の 1 です。
- **信号が読めるのは、rule の D = 24 だけです。**
  - rule の D = 50 と 100 は、どれも雑音の床に沈んでいます。
  - zipcyc は、どの深さでも床の下です。
- **規則 B は、このままでは雑音から計算した数字で判定されます。** zipcyc の L* は床の値から出ています。そのため、twin の κ（2.5〜2.9）には意味がありません。実機も twin と同じように振る舞えば、規則 B の κ は雑音から計算されます。一方で規則 B には、A と違って「床なら NOT JUDGED」の条項がありません。どうするかはオーナーの判断です（§5）。
- **QELM A の予想帯は、甘すぎる可能性があります。** 反響が速く消える理由は、QELM の特徴量にもそのまま当てはまると考えられます。ただし推論で、未確認です（§6）。いま回っている QELM の模擬機で確かめられます。

## 4. twin 自体の不確かさ（職場で追加の診断。結果ではありません）

**twin のスクリプトは SE を測っていません。** 当てはめには、名目の SE として 1/√64 を固定で使っています。そこで職場の CPU で、同じ記録（rule、hz 0、D = 24）を軌道ごとに計算し、ばらつきを見ました。スクリプトは `echo_twin_se_diag.py` で、TOQB 本体は変えていません。

**軌道ごとの値は、きれいに 2 つに分かれます。** 16 軌道の m（最大 19.25）を並べると、ほとんどは −1.5〜1.6 で、一部が 3.9、5.5、8.4、8.9、13.4、18.8 でした。

- 誤りの入った軌道は、ほぼ 0 になります。
- 誤りのない軌道だけが、大きな値を持ちます。
- 1 入力あたりの標準偏差は約 5.9 でした。

**さらに、4 つの入力は同じ乱数を使っています。** `z_all` が回路ごとに同じ種を使うためで、軌道ごとの値は 4 入力でほぼそろっていました。

**そのため twin の ρ_E（D = 24）の SE は、約 0.04 になります。**

- rule の D = 24 は、0.08〜0.10 ± 0.04 です。L* はおよそ 8〜12 です。
- hz による違い（0.084 → 0.099）は、この幅の中にあります。
  - hz の間でも乱数は共通なので、差の SE はもっと小さいはずですが、測っていません。
  - 「hz で L* が縮む」という宣言の見込みは、twin では確かめられません。

**静的 ZZ は主因ではありません。** 同じ乱数で ZZ を 0 にすると、4 軌道の m は 0.63 から 0.73 に変わっただけでした。主に効いているのは、T1・T2 とゲートの誤りです。

**速く消える理由（推論で、未確認）：**

- 電荷は、この回路の保存量です。ハイゼンベルク描像で時間を戻しても、局所的な項の和のまま広がりません。
- 反響で測る Z_j は保存量ではありません。時間を戻すと環全体に広がるので、どこで誤りが入っても値が消えます。
- そのため ρ_E は、回路全体の忠実度に近くなります。twin の 0.08 は、480 個の CZ の誤りに待機の誤りを足した見積もりと、桁が合います。

## 5. 実機への含み（twin と打数の模型から見た予想）

打数による SE（`se_model`、500 shots）は、n = 20 で約 0.005、n = 36 で約 0.004 です。

**規則 A。**

- 判定されるのは、ほぼ D = 24 のセルだけになりそうです。
  - rule の 0.08 前後は 2 SE を大きく超えるので、判定の対象になります。
  - zipcyc は 0 付近になるので、WIN になる見込みです。
- D = 50 と 100 は、両方の腕が床の下で、NOT JUDGED になる見込みです。
- 静的なブラインド Qiskit は、twin に入っていません。D = 24 の所要時間が rule の約 5 倍（38 対 8 µs）なので、これも床に近いと思われます。ただし未確認です。
- n = 36 では、ρ_E が忠実度のように量子数で効くなら、rule の D = 24 は 0.01 前後になります。2 SE（約 0.0075）すれすれです。粗い推論です。

**規則 B。**

- zipcyc はどの深さでも床の下になりそうなので、κ は雑音から計算されます。
- 規則 B には床の条項がなく、このまま計算すると INSIDE / OUTSIDE のどちらかが機械的に出ます。

**オーナーに決めてもらうこと（職場では何も変えていません）：**

- (i) **固定したまま実機で回す。** 判定は宣言どおりに出し、「zipcyc はすべての D で 2 SE 未満なので、κ は情報を持たない」と並べて報告します。
- (ii) **実機の前に、日付つきの追補を宣言に足す。** 規則 A と同じ原則で、「zipcyc に 2 SE を超えるセルがなければ、B は NOT JUDGED」とします。深さや hz は変えません。
- **深さを浅くする案は出しません。** twin の結果を見て深さを選ぶことになり、シミュレーションで選ぶことにあたるからです。

## 6. QELM A への警告（推論で、未確認）

**QELM A の予想帯は、ある仮定の上に立っています。** 特徴量が電荷と同じ速さで減衰する、という仮定です（宣言の §2、§9 に「仮定」と明記してあります）。この仮定で、rule の λ は exp(−19 / 56.5) = 0.71 としました。

**この仮定は外れているおそれがあります。** QELM の特徴量 ⟨X_q⟩・⟨Y_q⟩・⟨Z_q⟩ も保存量ではなく、L = 19 の回路を戻すと環全体に広がります。広がる量のおおよその和を比べると、反響の D = 24 と同程度です。

**もし λ が 0.1 前後なら：**

- S = 250 の実効打数は、λ²S ≈ 2〜3 になります。
- そうなると、どの腕も偶然（0.5）近くまで落ちます。
- 規則 Q2 は OUTSIDE になり、Q3a は検出力を失う見込みです。

いま回っている QELM の模擬機（rule と zipcyc）の結果で、これが確かめられます。twin の結果を受けて規則を変えるかどうかは、テスト 2 と同じくオーナーの判断です。
