## 2. S1：合成雑音のシミュレーション（`notes/s1_2026-11-05/s1_sim.py`）

  - それぞれの雑音の強さ：回転のずれ 5%、RZZ の角度 5%、静的 ZZ 0.02 rad/スロット、離調 0.02 rad/スロット、相手の振幅減衰 γ = 0.3/スロット（読み出し反転 40%）、止まった相手 γ = 1。
- **開示**：p2 は、最初 0.01 で1回走らせてから 0.004 に下げた。1ステップあたりの減衰を、11/04 の自分の往復の大きさ（0.98〜0.99）に合わせるためで、較正値は使っていない。ほかの強さは走らせる前に決め、変えていない。**実機に合わせ込んだ値ではない。** 見るべきなのは向きと θ の順で、大きさではない。

- **往復に見えない誤差**：回転のずれと止まった相手は、往復で打ち消される。順方向だけが損をし、補正し足りない側に出る。止まった相手は、損失が隣だけに出る（距離2は −0.036、距離3は +0.020）。
- **往復が過大に見る誤差**：常時の位相誤差（静的 ZZ、離調）と、揺らぐ相手。U と U† で同じ向きにかかり、打ち消されない。往復が順方向より速く減衰して、補正し過ぎになる。θx が大きいほど強く、θ0.8 で最大。
- **θ0.8 で往復の模型が外れる理由**：補正は「往復の減衰 = 順方向の減衰の2乗」を仮定している。
  - これが厳密に成り立つのは大域の脱分極のときだけ。
  - 局所のパウリ雑音では、順方向の信号は時間発展した Z_q のうち対角（I と Z だけ）の弦の重みで減衰し、往復は全部の弦の2乗の重みで減衰する。両者は一般に一致しない。
  - このシミュレーションでは、ずれは数 % 以内で、向きは「往復のほうが遅い」だった（補正し足りない側に −0.015）。
  - fez の +0.098（補正し過ぎ）を出せたのは、常時の位相誤差を入れたときだけ。
  - ただし、この強さでは θ0.53 でも補正し過ぎた（+0.18）。fez では θ0.53 が合っていたので、実機の常時誤差はこれより小さいはず。
